# Y-Learn Legal Documents 

This repository hosts the public legal documents for the Y-Learn mobile application.

Y-Learn is a mobile learning platform designed to support students and lecturers in managing courses, learning sessions, quizzes, link-based assignments, grades, academic feedback, and learning analytics.

## Public Legal Pages

The following legal documents are published through GitHub Pages:

- Privacy Policy: `privacy-policy.html`
- Terms and Conditions: `terms-and-conditions.html`

## GitHub Pages URL

After GitHub Pages is enabled, the documents will be available at:

- https://yeriksinggalen.github.io/ylearn-legal/privacy-policy.html
- https://yeriksinggalen.github.io/ylearn-legal/terms-and-conditions.html

## Purpose

These pages are used in the Y-Learn application registration screen and settings page to inform users about data handling, academic records, account responsibilities, and application usage terms.
